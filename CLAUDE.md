# Betül Alkan — Portfolio Website

CV / portfolio site for Betül Alkan, a Communication & Design student at Istanbul Gelişim
University (branding, UI/UX, video editing). Live at `betulalkan.com` (GitHub Pages, see `CNAME`).

## Current status: full redesign in progress

The current site (HTML/CSS/JS below) is being kept as a **reference**, not a locked target — it
is being redesigned from scratch. Treat the existing visual design, copy, and layout as raw
material and inspiration, not as constraints to preserve. It's fine to propose structural or
visual departures.

Note: the "Selected creations" work section in `content.js` (`work.projects`) currently uses
**placeholder content** (`work_belt_01.jpg`, generic titles like "Brand Identity System"). Betül's
actual project work lives in `PROJELER/` (source files) and `media/` (optimized output) but is not
yet wired into the site — see Media pipeline below.

## Stack

Static site, no build step, no framework, no package manager.

- `index.html` — single-page markup
- `style.css` — all styling (dark theme, custom properties at the top)
- `script.js` — all interactivity
- `content.js` — all copy, defines `SITE_CONTENT.en` and `SITE_CONTENT.tr` (bilingual site,
  language switch reads from this object — don't hardcode copy in HTML/JS)

## Local dev

```
powershell -File serve.ps1
```

Serves the repo root at `http://localhost:3500` (plain static file server, no live reload).

## Media pipeline

- `PROJELER/<project>/` — raw source screenshots/exports per project (not web-optimized, kept
  out of the served site)
- `media/<slug>/` — optimized output: `<n>.jpg` (max 1600px, q82, full view) and `<n>-t.jpg`
  (max 500px, q70, thumbnail), generated by `optimize-images.ps1`
- To add/update a project's images: drop sources in `PROJELER/<name>/`, add an entry to the
  `$map` in `optimize-images.ps1` (explicit file list, controls gallery order), then run:
  ```
  powershell -File optimize-images.ps1
  ```
- Known project slugs so far: `pigmentia`, `nox`, `catch`, `igu-obis`, `poster` (plus
  `petgrooming`, `olebaby` referenced in the script but not yet present under `PROJELER/`)

## Content editing

`content.js` copy (bio, project descriptions, titles, etc.) can be edited freely — no need to
confirm each wording tweak. Keep `en` and `tr` in sync when changing either.

## Design system (current, non-binding — see redesign note above)

- Dark theme, accent `#C8F135` (acid lime), fonts: Syne (display) / DM Sans (body) — defined as
  CSS custom properties at the top of `style.css`
- Since a redesign is planned, don't treat these as fixed; feel free to suggest alternatives

## Workflow expectations

- After any visual/CSS/layout change, start `serve.ps1` and check the result in the browser
  (screenshot or live view) before calling it done — don't just verify the code compiles/parses
- **Never `git push`** without asking first — this deploys straight to the live site at
  betulalkan.com via GitHub Pages. Commits are fine; pushing needs explicit confirmation each time
- Real contact info is already live in `content.js` (email `betulalkan98@gmail.com`, LinkedIn,
  Behance) — don't replace with placeholders
